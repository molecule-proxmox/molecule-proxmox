***********************
Molecule Proxmox Plugin
***********************

**molecule-proxmox** is an Ansible Molecule Driver plugin to manage instances
on a `Proxmox VE`_ hypervisor cluster.

Documentation: `https://molecule-proxmox.readthedocs.io <https://molecule-proxmox.readthedocs.io/>`_

.. _`Proxmox VE`: https://www.proxmox.com/en/proxmox-ve
